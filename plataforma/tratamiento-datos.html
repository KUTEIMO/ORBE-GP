Tratamiento de datos personales

Última actualización: 29 de septiembre de 2026 · Colombia (referencia Ley 1581 de 2012)

Aviso informativo para el piloto académico Orbe360. No constituye política corporativa ni registro ante la SIC. Un despliegue institucional real requeriría formalización con el responsable legal de la entidad.

Responsable del tratamiento (demo)

Proyecto académico Orbe360 — plataforma de recorridos 360° accesibles.
Contacto: orbe360.demo@proyecto.local

Finalidades del tratamiento

  1. Permitir el acceso y navegación en recorridos virtuales publicados.
  2. Gestionar cuentas de administradores y editores de tours (autenticación, roles).
  3. Almacenar y publicar contenido editorial (escenas, hotspots, textos, URLs de audio/subtítulos).
  4. Recordar preferencias de accesibilidad y de interfaz del usuario.
  5. Proteger el servicio (límite de intentos de login, trazas técnicas en demo).

Categorías de datos

  • Identificación y contacto: correo, nombre (usuarios registrados).
  • Credenciales: hash de contraseña (nunca texto plano en base de datos).
  • Datos técnicos: token de sesión, logs HTTP en infraestructura demo.
  • Preferencias: tema, idioma, opciones de accesibilidad (localStorage).
  • Contenido institucional: textos y metadatos de tours (responsabilidad del cliente demo, p. ej. Unisimón).

Derechos del titular (Ley 1581 — marco general)

Como titular de datos personales, en un entorno productivo formal podrías ejercer:

  • Conocer, actualizar y rectificar tus datos.
  • Solicitar prueba de la autorización otorgada (cuando aplique).
  • Revocar la autorización y/o solicitar supresión, salvo obligación legal o contractual.
  • Acceder gratuitamente a tus datos tratados.
  • Presentar quejas ante la Superintendencia de Industria y Comercio (SIC) si consideras vulnerados tus derechos.

En la demo académica, escribe a orbe360.demo@proyecto.local para ejercer estos derechos sobre datos de prueba.

Transferencia y encargados

  • Convex Inc. — procesamiento de datos en servidores en la nube (encargado del tratamiento técnico).
  • Cloudflare — túnel de demo pública (metadatos de tráfico).
  • Google — entrega de fuentes web (Google Fonts).

No vendemos datos personales. No hay publicidad comportamental en el código actual.

Medidas de seguridad (estado piloto)

Contraseñas con hash PBKDF2 (migración desde SHA-256 legacy), sesiones con expiración, roles por organización. Limitación conocida: token en localStorage (ver privacidad).

Vigencia

Los datos se conservan mientras dure el piloto académico o el periodo necesario para las finalidades descritas, salvo solicitud de supresión razonable en el contexto demo.

Personal data processing notice

Last updated: September 29, 2026 · Colombia (Law 1581 of 2012 reference)

Informational notice for the Orbe360 academic pilot. Not a corporate policy or SIC registration. A real institutional deployment requires formalization with the entity's legal owner.

Controller (demo)

Orbe360 academic project — accessible 360° tour platform.
Contact: orbe360.demo@proyecto.local

Purposes

  1. Enable access and navigation in published virtual tours.
  2. Manage administrator and editor accounts (authentication, roles).
  3. Store and publish editorial content (scenes, hotspots, copy, audio/caption URLs).
  4. Remember accessibility and UI preferences.
  5. Protect the service (login rate limits, technical traces in demo).

Data categories

  • Identity & contact: email, name (registered users).
  • Credentials: password hash (never plain text in DB).
  • Technical: session token, HTTP logs on demo infrastructure.
  • Preferences: theme, language, accessibility options (localStorage).
  • Institutional content: tour texts and metadata (demo client responsibility, e.g. Unisimón).

Data subject rights (Colombia — general frame)

In a formal production environment you could exercise access, rectification, deletion, revocation, and complaint rights before the SIC. For the academic demo, email orbe360.demo@proyecto.local.

Processors & transfers

  • Convex Inc. — cloud data processing.
  • Cloudflare — public demo tunnel.
  • Google — web fonts delivery.

We do not sell personal data. No behavioral advertising in current code.
