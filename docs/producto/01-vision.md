# Visión de producto — Plataforma de tours virtuales inclusivos

## Problema
Organizaciones (universidades, empresas, museos) necesitan recorridos 360° administrables, accesibles y publicables, sin depender de un desarrollador para cada cambio de hotspot o panorama.

## Producto
Plataforma SaaS-lite de **generación y administración de tours virtuales 360° inclusivos**:
- **Superadmin** gestiona clientes (organizaciones) y usuarios administradores.
- Cada **organización** tiene tours y editores.
- Cada **tour** tiene módulo admin (escenas, panoramas, hotspots, conexiones).
- El **visitante** consume demos/tours publicados con accesibilidad integrada (NFR).

## Primer cliente
Universidad Simón Bolívar — Cúcuta (tour campus / PEVCI piloto biblioteca).

## Fuera de alcance inmediato
Marketplace público global, LSC/Braille como Must del curso, multi-idioma completo.
